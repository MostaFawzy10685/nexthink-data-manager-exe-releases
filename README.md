# Nexthink Data Manager: releases

Installer downloads for Nexthink Data Manager for Windows. The current version is 3.7: `3.7/NexthinkDataManager-Setup-3.7.exe`.

Independent software by Mostafa Fawzy ([mostafawzy.com](https://mostafawzy.com)). Not affiliated with, endorsed by or sponsored by Nexthink. Nexthink is a trademark of its owner.

- The setup is signed with a self-signed certificate, so Windows shows the publisher as unknown unless you choose to trust that certificate on your own computers.
